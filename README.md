# Files for FDS Issue #16075

Figures and supporting files for the reply on https://github.com/firemodels/fds/issues/16075 (contact conduction between resting solid particles and surfaces).

The code is on the branch `particle-surface-heat-transfer`. This branch holds only these files.

- fig1_exact_cooling.png: sphere, cylinder and plate cooling on a fixed-temperature floor, FDS vs exact solution
- fig2_energy_budget.png: energy lost by the particles vs energy gained by the floor
- fig3_slab_heating.png: sphere on a thick slab, FDS vs Carslaw and Jaeger
- fig4_wessies_validation.png: FDS replica of Wessies and Ezekoye (2022), Fig. 13
- fig5_hot_rods.png: Verification/WUI/hot_rods with contact conduction
- 16075_supporting_files.zip: all verification and validation inputs, analysis scripts and results (README inside)
